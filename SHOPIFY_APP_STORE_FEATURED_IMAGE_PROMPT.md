# Prompt for AI Image Generation: Shopify App Store Featured Image

## App Context

**App name:** 1Click Archive and Empty Stock

**What it does:** A Shopify inventory management tool that lets merchants:
- Bulk archive products by conditions
- Scan and fix inventory policies
- One-click reset: set all stocked inventory to 0 across all locations and set variant policy to DENY (stop selling when out of stock)

**Target audience:** Shopify store owners and admins who need to quickly clear or archive inventory.

---

```

Show abstract product boxes or warehouse shelves transitioning from "full" to "empty" or "archived" state, with a single prominent action (e.g., a button or arrow) suggesting one-click simplicity. Include subtle UI elements like cards, metrics, or a minimal dashboard layout. Use a light, professional color palette (whites, light grays, soft blues or greens) that fits Shopify's admin aesthetic. No desktop backgrounds, no browser windows, no app logo as the sole focus. The image should convey speed, control, and simplicity for inventory management. Style: flat design, minimal, professional, suitable for e-commerce merchants.

## Shopify App Store Requirements (Compliance Checklist)

When generating or selecting the final image, ensure:

1. **4.4.4 – Clear, focused images**
   - Images should primarily show the app's actual user interface and features
   - No desktop backgrounds or browser windows
   - Feature images that solely contain the app logo are not permitted

2. **4.4.5 – Unique images**
   - Each image in the listing must be unique and showcase different features or views

3. **Other rules**
   - No pricing information in images
   - No stats, data, or unsubstantiated claims
   - No reviews or testimonials
   - Do not misuse Shopify trademarks

---

## Recommended Specifications

- **App icon:** 1200×1200 px, PNG or JPG, square, no rounded corners
- **Featured/screenshots:** Shopify does not publish fixed dimensions; use high resolution (e.g., 1200×800 or 1600×900) for clarity. Images should show the app UI or clearly illustrate app functionality.

---

## Notes for the AI Agent

- If the image generator produces a conceptual illustration, it should still suggest app functionality (inventory, archiving, one-click actions) rather than being purely decorative.
- For best compliance with 4.4.4, consider supplementing with actual app screenshots that show the real UI.
- Avoid generic "shopping cart" or "storefront" imagery; focus on inventory, stock levels, archiving, and admin/dashboard workflows.
